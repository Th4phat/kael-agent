## Installation

Install Kael from the source checkout, then configure Google Cloud Application
Default Credentials:

```bash
uv sync --frozen
```

## Setup

```bash
export KAEL_LLM="vertex_ai/gemini-3.1-pro-preview"
```

No API key required—uses Google Cloud Application Default Credentials.

## Authentication

### Option 1: gcloud CLI

```bash
gcloud auth application-default login
```

### Option 2: Service Account

```bash
export GOOGLE_APPLICATION_CREDENTIALS="/path/to/service-account.json"
```

## Example Model

| Model | Description |
|-------|-------------|
| `vertex_ai/gemini-3.1-pro-preview` | Gemini 3.1 Pro preview |

See the [Vertex AI model documentation](https://cloud.google.com/vertex-ai/generative-ai/docs/models)
for current model IDs, lifecycle state, and regional availability.

## Project Configuration

```bash
export VERTEXAI_PROJECT="your-project-id"
export VERTEXAI_LOCATION="global"
```

## Prerequisites

1. Enable the Vertex AI API in your Google Cloud project
2. Ensure your account has the `Vertex AI User` role
