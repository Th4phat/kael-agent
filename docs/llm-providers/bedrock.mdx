## Setup

```bash
export KAEL_LLM="bedrock/anthropic.claude-sonnet-4-6"
```

No API key required—uses AWS credentials from environment.

## Authentication

### Option 1: AWS CLI Profile

```bash
export AWS_PROFILE="your-profile"
export AWS_REGION="us-east-1"
```

### Option 2: Access Keys

```bash
export AWS_ACCESS_KEY_ID="AKIA..."
export AWS_SECRET_ACCESS_KEY="..."
export AWS_REGION="us-east-1"
```

### Option 3: IAM Role (EC2/ECS)

Automatically uses instance role credentials.

## Example Model

| Model | Description |
|-------|-------------|
| `bedrock/anthropic.claude-sonnet-4-6` | Claude Sonnet 4.6 |

Model IDs and regional availability vary. Confirm them in the
[Amazon Bedrock model catalog](https://docs.aws.amazon.com/bedrock/latest/userguide/model-cards.html).

## Prerequisites

1. Enable model access in the AWS Bedrock console
2. Ensure your IAM role/user has `bedrock:InvokeModel` permission
