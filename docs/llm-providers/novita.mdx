title: "Novita AI"

---

[Novita AI](https://novita.ai) exposes an OpenAI-compatible inference API.

## Setup

```bash
export KAEL_LLM="openai/<novita-model-id>"
export LLM_API_KEY="your-novita-api-key"
export LLM_API_BASE="https://api.novita.ai/openai"
```

Choose a current identifier from Novita's model catalog and confirm that the
model supports tool/function calling before starting a scan.

## Get an API key

1. Sign in at [novita.ai](https://novita.ai).
2. Open **API Keys** in the dashboard.
3. Create a key and store it outside version control.
