## Additional Tools

| Tool           | Purpose                                  |
| -------------- | ---------------------------------------- |
| Python Runtime | Write and execute custom exploit scripts |
| File Editor    | Read and modify source code              |
| Web Search     | Optional real-time OSINT via Perplexity  |
| Exploit Search | Find PoCs and exploit artifacts via Tavily |
| Exploit-DB Search | Direct Exploit-DB scrape (verified PoCs, no API key) |
| CVE Lookup     | CVSS / EPSS / KEV / ransomware intel from Shodan CVEDB |
| Notes          | Document findings during the scan        |
| Reporting      | Generate vulnerability reports with PoCs |
