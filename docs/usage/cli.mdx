## Top-level commands

```bash
kael [target] [keyword value ...]
kael scan [target] [keyword value ...]
kael resume [name]
kael list
kael show [name]
kael report [name]
kael sessions <command>
kael sandbox build [--force]
kael help
kael version
```

Run `kael help` for the complete sessions command tree.

## Scan keywords

| Keyword | Value | Default |
|---|---|---|
| `mode` | `quick`, `standard`, `deep`, `malware_re`, or `ctf` | `deep` |
| `instruction` | Instruction text | — |
| `instruction-file` | Path to instruction text | — |
| `prompt` | Prompt-only task text | — |
| `scope-mode` | `auto`, `diff`, or `full` | `auto` |
| `diff-base` | Git reference | Repository default |
| `config` | JSON configuration path | `~/.kael/cli-config.json` |
| `folder` | Override the local run-storage folder | `kael_runs` |
| `non-interactive` | Toggle; no value | Off |

`--build-sandbox` opts a scan into building a missing default image without an
interactive prompt.

## Examples

```bash
kael https://example.com
kael ./app mode standard
kael api.example.com instruction "Focus on authorization"
kael . non-interactive --build-sandbox mode quick
kael . non-interactive scope-mode diff diff-base origin/main
kael ./sample.exe mode malware_re
```

## Exit codes

| Code | Meaning |
|---|---|
| 0 | Command or scan completed successfully |
| 1 | Runtime, configuration, Docker, or provider error |
| 2 | Invalid CLI input, or one or more findings in a non-interactive scan |
