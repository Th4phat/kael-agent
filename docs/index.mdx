Kael coordinates AI agents inside a locally built security-tool sandbox. It
supports application-security assessment, CTF workflows, and malware reverse
engineering.

<Warning>
Only test systems you own or have explicit permission to assess.
</Warning>

Kael v0.1 is distributed from
[github.com/Th4phat/kael-agent](https://github.com/Th4phat/kael-agent). There is no official
hosted service, package-registry release, executable download, or container
image.

## Capabilities

- Source-aware and web application security testing
- Multi-agent coordination and local session management
- Browser, terminal, HTTP proxy, reconnaissance, and reporting tools
- CTF and malware reverse-engineering workflows
- Markdown, CSV, JSON, and SARIF results

## Minimal setup

```bash
git clone https://github.com/Th4phat/kael-agent.git
cd kael-agent
uv sync --frozen
export KAEL_LLM="openai/gpt-5.4"
export LLM_API_KEY="your-api-key"
uv run kael ./your-app
```

The first interactive scan asks before building `kael-sandbox:0.1.0` locally.
