## Setup

```bash
git clone https://github.com/Th4phat/kael-agent.git
cd kael-agent
make setup-dev
uv run kael sandbox build
```

Linux, Docker or Podman, and Python 3.12 or 3.13 are the supported contributor
baseline. Docker is used in CI.

## Workflow

1. Search or open an issue for substantial changes.
2. Branch from `main`.
3. Add tests and update user-facing documentation.
4. Run `make check`.
5. Submit a focused pull request with risks and validation evidence.

Use the `network` marker for real external services and `integration` for
container-runtime-dependent tests. Required unit checks must remain offline and
hermetic.

Read the repository [contribution guide](https://github.com/Th4phat/kael-agent/blob/main/CONTRIBUTING.md)
and [code of conduct](https://github.com/Th4phat/kael-agent/blob/main/CODE_OF_CONDUCT.md).

Use [Issues](https://github.com/Th4phat/kael-agent/issues) for bugs,
[Discussions](https://github.com/Th4phat/kael-agent/discussions) for questions, and
private vulnerability reporting for security issues.
