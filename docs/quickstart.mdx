## Prerequisites

- Linux
- Python 3.12 or 3.13
- [uv](https://docs.astral.sh/uv/)
- Docker with a running daemon, or Podman with an active API socket
- An LLM provider API key

## Install from source

```bash
git clone https://github.com/Th4phat/kael-agent.git
cd kael-agent
uv sync --frozen
```

For rootless Podman:

```bash
systemctl --user start podman.socket
export KAEL_RUNTIME_BACKEND=podman
export KAEL_CONTAINER_SOCKET="/run/user/$(id -u)/podman/podman.sock"
```

## Configure a provider

```bash
export KAEL_LLM="openai/gpt-5.4"
export LLM_API_KEY="your-api-key"
```

## Build and scan

```bash
# Optional: build before the first run instead of accepting the prompt.
uv run kael sandbox build

# Scan a local source tree.
uv run kael ./your-app
```

The sandbox image is built locally and tagged `kael-sandbox:0.1.0`. Results
are saved under `kael_runs/`.

For non-interactive runs, opt into a missing-image build explicitly:

```bash
uv run kael ./your-app non-interactive --build-sandbox mode quick
```

<Note>
Kael v0.1 does not publish a PyPI package, executable installer, hosted service,
or container image.
</Note>
